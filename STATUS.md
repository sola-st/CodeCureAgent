# List of Badges That We Apply For

- **Evaluated - Functional**: We provide all code, data, and evaluation results for all experiments described in the paper. The code is well-documented and can be used to run the same evaluation on your own machine. The evaluation results are reproducible.
- **Evaluated - Reusable**: The code is easily reusable for reproducing the experiments, but also for running new experiments, or for adapting the code to new use cases. We provide a Devcontainer for easy setup and development using VS Code, as well as a pre-built Docker container for portability.
We provide utility scripts and documentation for running your own experiments. The code is modular and well-documented, making it easy to understand and modify.
- **Available**: The complete codebase with all data is publicly and permanently available on Zenodo with a DOI.
