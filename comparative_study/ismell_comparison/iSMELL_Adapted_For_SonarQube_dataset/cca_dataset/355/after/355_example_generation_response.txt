```java
// Noncompliant code example
public void nestedTryCatch() {
    try {
        // some code that might throw ExceptionA
        try {
            // some code that might throw ExceptionB
        } catch (ExceptionB e) {
            // handle ExceptionB
        }
    } catch (ExceptionA e) {
        // handle ExceptionA
    }
}

// Compliant solution
public void flatTryCatch() {
    try {
        // some code that might throw ExceptionA
        // some code that might throw ExceptionB
    } catch (ExceptionB e) {
        // handle ExceptionB
    } catch (ExceptionA e) {
        // handle ExceptionA
    }
}
```
